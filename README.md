# LLM API Assignment

This project demonstrates how to access two Large Language Model APIs using Python:

1. OpenAI GPT API
2. Google Gemini API

## Technologies Used

- Python
- OpenAI API
- Google Gemini API
- OpenAI Python SDK
- Google GenAI SDK
- python-dotenv
